# Security Policy

## Supported Versions

This is a small educational project. Security updates are provided for the latest version available on the `main` branch.

|         Version          | Supported |
| ------------------------ | --------- |
| Latest version on `main` |    Yes    |
| Older versions           |    No     |

## Reporting a Vulnerability

Please do not report security vulnerabilities through a public GitHub issue.

Instead, contact the repository maintainer privately through GitHub. Include:

- A description of the vulnerability
- Steps to reproduce it
- The possible impact
- Any suggested fix

Please allow reasonable time for the report to be reviewed before publicly disclosing the vulnerability.
