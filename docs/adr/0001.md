# 0001 - Use MiniLibX for rendering

Date: 2026-07-21

## Status
Accepted

## Context
This project is a small Linux C Mandelbrot viewer that must render graphics and handle mouse/keyboard input.
The repo already includes a bundled `minilibx-linux` dependency.

## Decision
Use MiniLibX for graphics and event handling, keeping the implementation simple and tied to the existing build flow.

## Consequences
- Keeps the project lightweight and focused on the fractal viewer.
- Requires Linux/X11 and the bundled MiniLibX library.
- Limits portability compared to SDL2 or GLFW.

## Rationale
MiniLibX fits the repo goals by providing a minimal graphics layer, direct pixel access, and input hooks without adding a larger external toolkit.
